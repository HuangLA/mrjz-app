# Web 管理后台方案

最后更新：2026-05-13

## 1. 定位

Web Admin 是赛事运营人员的数据控制台。它承担所有复杂写操作：赛季、队伍、选手、赛程、赛果、match_id、OpenDota 同步和权限管理。微信小程序和手机网页 H5 只展示公开赛事数据、用户个人数据和必要互动，不承载复杂后台表单。

这个切分更适合实际运营：管理员在电脑上处理表格、筛选和批量录入，小程序和 H5 保持轻量、稳定、容易发布。

## 2. 技术建议

- React + TypeScript + Vite
- Ant Design
- React Router
- TanStack Query + Axios
- 独立构建为静态资源，由 Nginx 部署

目录：

```text
apps/admin/
  src/
    pages/
    components/
    layouts/
    api/
    hooks/
    routes/
```

## 3. 权限

角色：

- `team_admin`：维护本队资料、成员和提交本队比赛 match_id。
- `tournament_admin`：维护赛季、队伍、选手、赛程、赛果、同步任务。
- `super_admin`：管理管理员账号、角色、系统配置。

MVP 使用账号密码登录：

- 超级管理员通过 seed 初始化。
- 密码只保存哈希。
- 登录态与小程序 token 分离。
- 后续可加二次验证或微信扫码登录。

## 4. 页面

### 4.1 登录页

功能：

- 用户名、密码登录。
- 登录失败提示。
- 记住登录状态，默认短有效期。

验收：

- 非管理员无法登录。
- 登录失败不暴露账号是否存在。

### 4.2 工作台

功能：

- 当前赛季概览。
- 待补录赛果。
- 同步失败任务。
- 近期赛程。
- 最近同步记录。

验收：

- 管理员进入后能立刻知道今天该处理什么。

### 4.3 赛季与联赛

功能：

- 创建、编辑、启停赛季。
- 配置 OpenDota league_id。
- 设置默认展示赛季。

验收：

- 同一时间只能有一个默认赛季。
- league_id 修改需要二次确认。

### 4.4 队伍管理

功能：

- 队伍列表、搜索、筛选。
- 创建和编辑队伍名、简称、Logo、颜色。
- 管理队伍成员。

验收：

- 队伍名和简称在同赛季内不能重复。

### 4.5 选手管理

功能：

- 创建和编辑选手。
- 维护 Dota 2 account_id、steam_id64、展示昵称、头像。
- 审核用户绑定申请。

验收：

- 同一个 Dota 2 account_id 不能绑定多个选手。
- 绑定审核必须记录操作者。

### 4.6 赛程管理

功能：

- 赛程列表：赛季、阶段、队伍、状态筛选。
- 创建 BO1、BO2、BO3 等 series。
- 设置计划时间、双方队伍、备注。
- 修改状态：未开始、已确认、进行中、待补录、已完赛、延期、取消。

验收：

- 已完赛但没有 match_id 的比赛可以显示人工赛果。
- 延期和取消必须填写原因。

### 4.7 赛果录入

功能：

- 为每一局录入比分、胜方、match_id。
- 检测 OpenDota 返回结果与人工结果是否冲突。
- 允许解绑错误 match_id 并重新关联。

验收：

- 重复 match_id 不允许保存。
- 人工胜方与 OpenDota 胜方冲突时进入“待确认”。

### 4.8 数据同步

功能：

- 按 match_id 同步单场比赛。
- 按 league_id 同步新比赛。
- 请求 OpenDota 解析。
- 查看同步进度、失败原因、重试。

验收：

- 同步任务可追踪状态。
- 外部接口失败不会影响用户侧已有缓存数据。

### 4.9 互动标签管理

功能：

- 查看选手标签和队伍标签。
- 按目标类型、目标名称、创建用户、点赞数、状态筛选。
- 隐藏违规标签、恢复误隐藏标签。
- 查看标签创建人、创建时间、点赞数和举报记录。

验收：

- 隐藏标签需要填写原因。
- 普通用户无法看到已隐藏标签。
- 标签隐藏、恢复都必须进入审计日志。

### 4.10 权限与审计

功能：

- 管理管理员账号。
- 分配角色和作用范围。
- 查看审计日志。

验收：

- 所有写操作必须记录旧值、新值、操作者和时间。
- 超级管理员不能删除自己的最后一个超级管理员权限。

## 5. 部署

推荐部署到云服务器：

```text
admin.example.com    -> Nginx 静态站点
api.example.com/api  -> Nginx 反向代理到 Express API
```

最低要求：

- HTTPS。
- 管理后台域名不配置到小程序，只给管理员使用。
- API 域名配置到小程序 request 合法域名，并允许 H5 域名跨域访问。
- 数据库每日备份。
- 日志保留至少 14 天。
